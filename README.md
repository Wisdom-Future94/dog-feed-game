# 吧唧狗狗 2.0 · 空间投喂原型

验证核心循环：瞄准蓄力、空间投掷、狗狗跳跃张嘴接食、失误掉地、真实音效反馈、30 秒结算集体跳舞。

## 本地运行

```bash
cd /home/admin/dog-feed-game
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080/`。支持鼠标拖动和触屏拖动。

## 当前范围

- 3 只处于前中后三个纵深位置的卡通狗
- 狗狗抬头追踪、跳跃张嘴、摇尾巴和落地反馈
- 5 种食物 Emoji 占位素材
- 按拖动方向和距离控制投掷方向与力度
- 抛物线投掷、接住/掉地两种结果
- 连击、计分、30 秒回合
- Web Audio 生成的无版权基础音效
- 回合结束集体跳舞与结算

当前狗狗使用程序绘制的 2.5D 卡通造型，下一步可替换为正式低多边形 3D 模型、原创 BGM 和微信小游戏 Canvas 工程结构。
