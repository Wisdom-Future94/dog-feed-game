# 吧唧狗狗 · 原型

第一阶段验证核心玩法：抛食物、狗狗跳跃接食、吧唧反馈、30 秒结算集体跳舞。

## 本地运行

```bash
cd /home/admin/dog-feed-game
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080/`。支持鼠标拖动和触屏拖动。

## 当前范围

- 3 只不同颜色与名字的卡通狗
- 5 种食物 Emoji 占位素材
- 抛物线投掷与接食判定
- 连击、计分、30 秒回合
- Web Audio 生成的无版权基础音效
- 回合结束集体跳舞与结算
